# Sprint Support Convention

Students can ask inside the pinned weekly support thread or open a dedicated Skool topic.

## Tags

- Week 1: `[W1][#00]` or `[W1][#01]`
- Week 2: `[W2][#02]` or `[W2][#03]`
- Week 3: `[W3][#04]` or `[W3][#05]`
- Week 4: `[W4][#06]` or `[W4][#07]`
- Week 5: `[W5][#08]`

## Question Template

```text
[WEEK][TASK] Short description

Goal:

Expected:

Actual:

Command or failing eval:

Smallest relevant code/event excerpt:

Already tried:
```

## Safety

Remove API keys, `.env` values, Pi auth files, customer data, private URLs, and unrelated production logs before posting.
